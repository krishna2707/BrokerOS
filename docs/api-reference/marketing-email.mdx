The Marketing Email API manages high-volume marketing and transactional email campaigns through providers including SendGrid, Brevo, AWS SES, and Mailchimp. It handles audience segmentation, SPF/DKIM domain verification, dynamic personalization, and tracking webhooks.

```http
BASE URL: /api/marketing
```

---

## Endpoints Summary

| Method | Path | Description | Access |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/marketing/campaigns` | List email campaigns with pagination and filters | Marketing / Admin |

| `GET` | `/api/marketing/campaigns/:id/analytics` | Open rates, click maps, bounces, and unsubscribes | Marketing / Admin |
| `GET` | `/api/marketing/campaigns/:id/recipients` | Paginated recipient engagement status log | Marketing / Admin |

## Create Email Campaign

```http
POST /api/marketing/campaigns
```

### Request Body

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string` | **Yes** | Campaign internal title |
| `subject` | `string` | **Yes** | Email subject line with optional merge tags |
| `previewText` | `string` | No | Inbox preview preheader snippet |
| `fromName` | `string` | **Yes** | Sender display name (e.g. `BrokerOS Luxury Collection`) |
| `fromEmail` | `string` | **Yes** | Verified sender email (e.g. `sales@properties.yourfirm.com`) |
| `replyTo` | `string` | No | Destination email for direct client replies |
| `htmlContent` | `string` | **Yes** | Responsive HTML email body |
| `projectId` | `string` | No | Target project UUID |
| `audienceSource` | `string` | **Yes** | `CRM_LEADS` or `CSV_UPLOAD` |
| `targetCriteria` | `object` | No | Status, temperature, or budget filters |

### Request Example

```json
{
  "name": "Emerald Heights - Tower B Official Unveiling",
  "subject": "Exclusive Preview: Luxury 3BHK Homes in Whitefield",
  "previewText": "Private invitation for priority booking this weekend",
  "fromName": "Emerald Heights Sales Team",
  "fromEmail": "sales@emeraldheights.com",
  "replyTo": "concierge@emeraldheights.com",
  "htmlContent": "<html><body><h1>Hello {{firstName}},</h1><p>You are cordially invited...</p></body></html>",
  "projectId": "cm123proj001",
  "audienceSource": "CRM_LEADS",
  "targetCriteria": {
    "leadStatuses": ["CONTACTED", "INTERESTED"],
    "leadTemperatures": ["HOT", "WARM"]
  }
}
```

## Send Test Email

```http
POST /api/marketing/campaigns/send-test
```

Sends an immediate preview email to your inbox to check layout rendering across desktop and mobile clients (Apple Mail, Gmail, Outlook).

### Request Body

```json
{
  "toEmail": "marketing.lead@yourfirm.com",
  "subject": "[TEST PREVIEW] Exclusive Preview: Luxury 3BHK Homes",
  "htmlContent": "<html>...</html>",
  "sampleData": {
    "firstName": "Rahul",
    "project": "Emerald Heights"
  }
}
```

## Dispatch Campaign

```http
POST /api/marketing/campaigns/:id/dispatch
```

Transitions campaign status to `SENDING` and delegates email batch processing to `apps/workers/src/marketing-email.processor.ts`.
