## Base URL

```
https://api.yourdomain.com
```

All endpoints begin with `/api`. For local development:
```
http://localhost:3001
```

---

## Authentication

All endpoints (except where marked **Public**) require a valid Better Auth session. Include the session cookie in every request — it is set automatically by the browser after login.

For programmatic access (e.g. mobile app background services, scripts), pass the session token as a Bearer header:

```http
Authorization: Bearer <session_token>
```

Read the full auth guide → [Authentication](/api-reference/authentication)

---

## Response Format

All responses are JSON. Successful responses return the data directly (object or array). Errors follow this shape:

```json
{
  "statusCode": 400,
  "message": "phone must be a string",
  "error": "Bad Request"
}
```

---

## Role-Based Access

Most endpoints check the authenticated user's role before responding. If your role does not have access, you receive:

```json
{
  "statusCode": 403,
  "message": "Forbidden resource"
}
```

The role is **always read from the server-side session** — never from the request body.
