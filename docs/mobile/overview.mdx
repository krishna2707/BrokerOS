## What is the Mobile App?

The BrokerOS mobile app is an enterprise **native Android application** built with **Expo 54**, **React Native 0.81**, and **React 19**, with the React Native New Architecture enabled. It serves as the primary operational tool for real estate professionals working in the field or conducting high-velocity telecalling.

While the Next.js web application is designed for management oversight and marketing campaign orchestration, **the Android mobile app is where field execution happens**:
- Pre-sales agents call through daily queues using the native auto-dialer
- Sales executives conduct GPS-verified site visits and submit on-site booking locks
- Sourcing managers register new channel partners and verify RERA credentials
- Closing managers negotiate unit discounts with buyers on-site
- Post-sales executives track collection milestones and loan case approvals

## Technical Foundation

| Layer | Technology | Key Capabilities |
| :--- | :--- | :--- |
| **Framework** | Expo 54 / React Native 0.81 | React 19 runtime, New Architecture enabled, TurboModules. |
| **Routing** | Expo Router 6 | File-based typed routing (`app/` directory), deep linking. |
| **Styling** | NativeWind v4 (Tailwind CSS v3) | Fast, utility-driven styling using `className` props. |
| **Authentication** | Better Auth (`@better-auth/expo`) | Hardware-backed session persistence via `expo-secure-store`. |
| **Native Module** | Custom Kotlin Auto-Dialer | Telephony broadcast receiver, Jetpack WorkManager background upload. |
| **Realtime Engine** | Socket.IO Client (`socket.io-client`) | Bidirectional WebSocket communication for chat and notifications. |
| **Location Engine** | `expo-location` + `expo-task-manager` | 1-minute background GPS tracking with persistent foreground notification. |
| **Maps & Camera** | `react-native-maps` + `expo-image-picker` | Native Google Maps rendering and live selfie capture. |

## Operating System & Device Target

<Note>
  The BrokerOS mobile application is strictly configured for **Android** (Android 8.0 / API 26 and above). There is no iOS build configuration. Real estate sales forces in this target enterprise market use Android handsets exclusively, enabling native telephony hooks, Storage Access Framework audio ingestion, and background location services that are restricted under iOS sandbox limitations.
</Note>

## Development & Distribution Workflow

Because the mobile application relies on custom native Kotlin code inside [`modules/auto-dialer/`](https://github.com/trybrokeros/BrokerOS/blob/main/apps/mobile/modules/auto-dialer/), it cannot be launched inside the generic Expo Go client from Google Play.

1. **Local Development Builds**: Developers run `npx expo run:android` to compile a custom development APK directly onto a connected physical Android phone or Android Studio emulator.
2. **Internal Distribution APK**: Built on EAS infrastructure (`eas build --platform android --profile preview`) and distributed directly to brokerage staff without Google Play Store delays.
3. **Over-The-Air (OTA) Updates**: Routine JavaScript, styling, and business logic patches are delivered silently to employee devices via EAS Update, requiring zero manual APK reinstalls.

For step-by-step workstation setup, Google Maps keys, Firebase configuration, and build instructions, visit the [Mobile Setup and Tooling Guide](/mobile/app/setup-and-tools).
